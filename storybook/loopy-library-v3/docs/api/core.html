Docs/API reference/Core

Core tools

Small building blocks for files and URLs: turn text into bytes, calculate hashes and reject unsafe addresses or paths. Other modules use these behind the scenes.

Try it in context: Read the guide.

import { Core } from '@chaoticka/nsite-loopy-sdk';

What you can call (11)

bytes

Turn text or binary input into the bytes that hashing and publishing need.

Call it as: Core.bytes

For developers: TypeScript signature

function bytes(value:string|Uint8Array|ArrayBuffer):Uint8Array;

Code location: src/core/bytes.js

encode

Convert ordinary text into UTF-8 bytes.

Call it as: Core.encode

For developers: TypeScript signature

function encode(value:string):Uint8Array;

Code location: src/core/bytes.js

For developers: TypeScript signature
