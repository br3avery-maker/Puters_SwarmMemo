Docs/API reference/Anchor

Anchor tools

Keep Nostr account settings portable, look up event kinds, evaluate relay suitability and understand what a publication receipt actually proves.

Try it in context: Read the guide.

import { Anchor } from '@chaoticka/nsite-loopy-sdk';

What you can call (9)

assessRelayOutbox

Evaluate whether a relay is suitable for posting based on observed health and policy.

Call it as: Anchor.assessRelayOutbox

For developers: TypeScript signature

function assessRelayOutbox(relay?:object):{status:string;role:string;reasons:string[];verified:boolean};

Code location: src/anchor/relays.js

buildPublicAccountBackup

Save portable public account settings without exporting private keys or signer secrets.

Call it as: Anchor.buildPublicAccountBackup

For developers: TypeScript signature

function buildPublicAccountBackup(state:object,options?:{now?:number}):object;

Code location: src/anchor/index.js

classifyEventStorage

Identify how a Nostr event kind is normally stored and replaced.

Call it as: Anchor.classifyEventStorage

For developers: TypeScript signature

function classifyEventStorage(kind:number):'regular'|'replaceable'|'ephemeral'|'addressable';

Code location: src/anchor/kinds.js

extractEventAssets

List media attachments mentioned in a verified event without downloading them.

Call it as: Anchor.extractEventAssets

For developers: TypeScript signature

function extractEventAssets(event:SignedEvent):string[];

Code location: src/anchor/index.js
