Docs/API reference/Nsite

Nsite tools

Make and publish static Nostr websites. These functions check your site files, prepare a signed manifest and help other people find the website.

Try it in context: Read the guide.

import { Nsite } from '@chaoticka/nsite-loopy-sdk';

What you can call (10)

NSITE_NAMED_KIND

Nostr event kind used to announce a named nsite.

Call it as: Nsite.NSITE_NAMED_KIND

For developers: TypeScript signature

const NSITE_NAMED_KIND:35128;

Code location: src/nsite/manifest.js

NSITE_ROOT_KIND

Nostr event kind used to announce the website at an account’s root.

Call it as: Nsite.NSITE_ROOT_KIND

For developers: TypeScript signature

const NSITE_ROOT_KIND:15128;

Code location: src/nsite/manifest.js

Show which site files were added, removed or changed between two versions.

For developers: TypeScript signature
