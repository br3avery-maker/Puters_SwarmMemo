Docs/API reference/Nostr

Nostr tools

Sign in with a real account, prepare and verify posts, discover relays, and read or publish Nostr events. This is the part a social app like Deepink uses most.

Try it in context: Read the guide.

import { Nostr } from '@chaoticka/nsite-loopy-sdk';
