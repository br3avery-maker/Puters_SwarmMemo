Docs/API reference/Choose a function

Find the function you need

The API is the menu of things other apps can ask Loopy to do. You do not have to use the whole library: import the part you need, call its function and handle the result.

Not sure where to start? Use the guides for real tasks, or search for words like block publisher, sign in, upload image or save ZIP.

Import a module

import { Nostr, Moderation, Moji } from '@chaoticka/nsite-loopy-sdk';

The module pages show what each function is for first, followed by its exact TypeScript call signature and source file. Technical details are for developers and agents who want to reuse the code.
