Docs/API reference/Adapters

Adapters tools

Connect Loopy to the environment it runs in, including browsers and native Android apps that can return Amber signing results.

Try it in context: Read the guide.

import { Adapters } from '@chaoticka/nsite-loopy-sdk';

What you can call (2)

androidHandoff

Connect the web library to a native Android host that can launch Amber and return its result.

Call it as: Adapters.androidHandoff

For developers: TypeScript signature

function androidHandoff(options:{launch:(uri:string)=>Promise<void>;onReturn:(requestId:string)=>Promise<{id:string;event:SignedEvent;rejected?:boolean}>}):{sign(options:{requestId:string;event:UnsignedEvent;expectedPubkey:Hex}):Promise<SignedEvent>};

Code location: src/adapters/android.js

browserEnvironment

Inspect which browser capabilities—signer, storage and network—are actually available.

Call it as: Adapters.browserEnvironment

For developers: TypeScript signature

function browserEnvironment(options?:object):{signer:Signer|null;storage:StorageAdapter|null;Socket:any;fetcher:typeof fetch};

Code location: src/adapters/browser.js
