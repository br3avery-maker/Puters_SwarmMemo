Docs/API reference/Moji

Moji tools

Work with real Nostr emoji packs, give media stable identities, deduplicate them and reuse MojiSurvivor’s deterministic game traits.

Try it in context: Read the guide.

import { Moji } from '@chaoticka/nsite-loopy-sdk';

What you can call (7)

buildStableEmojiKey

Give an emoji media item a stable identifier independent of its shortcode.

Call it as: Moji.buildStableEmojiKey

For developers: TypeScript signature

function buildStableEmojiKey(url:string,source?:'nip30'|'reserve',hashOverride?:Hex):Promise<string>;

Code location: src/moji/index.js

collectNip30Emojis

Collect matching Nostr emoji packs, deduplicate them and report excluded items.

Call it as: Moji.collectNip30Emojis

For developers: TypeScript signature

function collectNip30Emojis(events:SignedEvent[],options?:{policy?:object;max?:number}):Promise<{emojis:object[];rejected:object[];unresolvedReferences:string[]}>;

Code location: src/moji/index.js

deriveEmojiStats

Generate Moji game traits and rarity from an emoji’s stable media identity.

Call it as: Moji.deriveEmojiStats

For developers: TypeScript signature

function deriveEmojiStats(options:{shortcode:string;url:string;source?:'nip30'|'reserve';hashOverride?:Hex}):Promise<object>;

Code location: src/moji/index.js
