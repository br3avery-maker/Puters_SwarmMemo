Docs/API reference/Archive

Archive tools

Back up nsites and other files, keep versions, recognize duplicate content and reconstruct original bytes when you need them.

Try it in context: Read the guide.

import { Archive } from '@chaoticka/nsite-loopy-sdk';

What you can call (13)

GEAR_PROFILE

The size limits and identifier for Loopy’s internal content-defined chunking strategy.

Call it as: Archive.GEAR_PROFILE

For developers: TypeScript signature

const GEAR_PROFILE: Readonly<{id:string;min:number;avg:number;max:number}>;

Code location: src/archive/chunks.js
