What is tested—and what still needs a real device

The library has passing offline tests, but a phone, Amber and public relays are separate systems. This page is the place to check whether a feature was tested locally, on a device, or on the live network.

Area Locally tested Not established by this release
Event signatures BIP-340 signing and verification Approval in a real installed signer
NIP-46 Adapter and request-contract tests Actual same-phone live approval/reconnect
NIP-55 Intent construction and result-validation tests Android ActivityResult and app-switch behavior
Relays Mock transport, NIP-65 discovery, receipt logic Real production relay persistence across hosts
Blossom Injected transport, hash validation and readback Real server authorization/quotas and delivery
Nsites Manifest preparation, signing, checkpoint pipeline Public live nsite deployment from this SDK
Archives ZIP/CAS/version and rejection tests Every historical source file behaves as a module
Browser UI Not included in SDK; docs are static A built Deepink consumer

The SDK is not published to npm, and this documentation is packaged for static hosting rather than already live on a public URL. Tests describe how to raise these verification levels.
