Docs/Guides/Anchor & recovery

Keep an account portable between apps

Anchor provides account setup and recovery tools. Loopy can save public profile and relay settings, inspect publication receipts and restore an account in read-only mode until you approve a signer again.

import { Anchor } from '@chaoticka/nsite-loopy-sdk';
const saved = Anchor.buildPublicAccountBackup({session: currentPublicSession, profile, publications});
const recovered = Anchor.restorePublicAccountBackup(saved);
// recovered.signerConnected === false; reapprove signer before signing again.

Backups redact secret fields and exclude authenticated signer runtime state. Restores verify stored signed publication events and remain read-only. A recalled login is never evidence of ongoing authorization.

Anchor.planVerifiedOutbox only recommends relay writes when actual write probes were recorded; other relays are audit candidates. Anchor.summarizePublicationReceipts never counts accepted relay OK as independently retrieved. These are network-result consumers, not a network scanner.
