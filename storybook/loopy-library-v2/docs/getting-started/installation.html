Installation

The SDK is an ES module with no network side effects on import. Node.js 20+ supports local scripts and tests. For live interactions, use a runtime with WebSocket, fetch, Web Crypto, and an authorized signer.

Install from the provided npm tarball

npm install ./chaoticka-nsite-loopy-sdk-1.0.0.tgz

Or install directly from the extracted SDK directory:

npm install /absolute/path/to/Nsite-Loopy-Unified-SDK-1.0.0

This release was delivered as a local artifact, not published to the public npm registry. The scope/name does not imply registry availability.

Import a namespace

import { Nostr, Nsite, Blossom, Archive, Directory } from '@chaoticka/nsite-loopy-sdk';
import { createNsiteSDK } from '@chaoticka/nsite-loopy-sdk';

You can also import an individual namespace entry point, for example:

import * as Nostr from '@chaoticka/nsite-loopy-sdk/nostr';

Verify the source package

From the extracted SDK directory, run:

npm test
npm run test:types
npm run verify

The release receipt records 43 JavaScript tests, 10 Python tests, plus clean npm consumer/type checks. Those tests do not authorize a deployment or prove a signer popup worked on a phone.
