What agents can help with

These are the jobs we have already taught agents how to do with Loopy. Pick one based on the thing you need fixed or built. The detailed instructions are for the agent; you do not need to learn the commands.

Pick a job

  • Find code we already built — Before writing another tool, look through related repositories for an existing implementation. Extract useful pieces, check them with tests, and add only the missing capabilities to Loopy.
  • Connect Amber or another Nostr signer — Help an app ask your existing signer for permission and recognize the real response—so opening Amber or copying an npub never gets mistaken for a successful login.
  • Turn a demo social app into a real client — Keep the app’s interface but connect its posts, profiles, replies, reactions and images to genuine Nostr accounts, relays and Blossom storage.
  • Organize a collection of nsites — Group versions and clones, use search and filters, hide spam or blocked publishers, and preserve the original files so nothing is lost.
  • Publish a website to Nostr — Prepare website files, upload them to Blossom, sign the site manifest and independently check that relays received the publication.
  • Rebuild an nsite from a saved copy — Recover the exact site files from a manifest, a ZIP, or a local archive and keep the original versions and hashes.
  • Find an account’s relay and storage servers — Use the account’s signed server preferences instead of forcing you to configure the same relays and Blossom hosts in every new app.
  • Extract useful functions from old projects — Take working code from source archives and turn it into standard APIs with tests and documentation, rather than creating another incompatible app-specific copy.
  • Check and package a reusable library — Test the SDK from a clean install, package the actual code and docs, and keep reproducible copies and verification records.
