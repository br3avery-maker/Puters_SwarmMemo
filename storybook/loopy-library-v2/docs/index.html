Build Nostr software without rebuilding everything

Loopy Library keeps us from reinventing the same Nostr code for every new app. It brings together the tools for signing in, finding relays, posting, storing pictures, publishing websites, blocking spam, handling emoji packs and saving archives—so projects like Deepink can reuse them.

Under the hood, this is a JavaScript/TypeScript library with 11 modules and 140 direct exports, plus three convenience API entries. You can use one module at a time or the whole kit.

import { createNsiteSDK, Nostr, Archive } from '@chaoticka/nsite-loopy-sdk';

const note = Nostr.textNote('Hello from Deepink');
const zip = Archive.writeZip({ 'index.html': '<h1>Hello, nsite!</h1>' });
console.log(note.kind, zip.length); // no network or credentials used

Pick your path

  • Install the SDK — use the local npm archive or source package.
  • Explore the API — all exported symbols, grouped by module, with TypeScript declarations.
  • Sign with Amber — NIP-55 Android handoff and NIP-46 remote signing.
  • Discover relays — NIP-65 routing and NIP-11 metadata.
  • Publish an nsite — Blob upload, manifest signing, and exact-ID relay readback.
  • Make Deepink real — the existing app's integration contract.

What we mean by reusable

Each function has a source, an explanation and tests. The private recovery archive keeps the originals separately. When something still needs a real phone, signer or relay test, the verification page says so.
